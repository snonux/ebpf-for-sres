Example 01

Opens per process, two ways

bpftrace

tracepoint:syscalls:sys_enter_openat
{
    @[comm] = count();
}

Four lines. bpftrace creates the map keyed by process name, does the lookup and the atomic increment, and prints the map on Ctrl-C.

The C version on the right spells out each of those steps. The Go side only loads it, waits and prints the map.

libbpf C + Go (kernel side)

SEC("tracepoint/syscalls/sys_enter_openat")
int count_opens(void *ctx) {
    char comm[16] = {};
    bpf_get_current_comm(&comm, 16);
    u64 one = 1, *n =
        bpf_map_lookup_elem(&counts, &comm);
    if (n) __sync_fetch_and_add(n, 1);
    else bpf_map_update_elem(&counts,
                &comm, &one, BPF_NOEXIST);
    return 0;
}

The command from the cover slide, in the two flavours every example in the repository comes in. bpftrace is four lines. The C version spells out what bpftrace does for you: a hash map keyed by process name, a lookup, an atomic increment. The Go side, which we will see later, just loads this, waits and prints the map. Seeing both once makes the rest of the examples easier to read.
