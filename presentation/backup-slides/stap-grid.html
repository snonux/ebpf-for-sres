On the grid: many hosts

Ad hoc

The same one-liner on every host, in parallel, with a timeout, then aggregate: ansible all -m shell -a "timeout 10 bpftrace -e '…'"

Packaged

bpftrace and bcc-tools come from dnf on every Rocky 9 box: no extra repos.

Shipped

A static CO-RE binary goes out with your config management: no compiler or headers on the fleet.

examples/01 to 06/ · every one also has a .stp version

Many of you know SystemTap, which did all of this years before BPF and has a richer language. The difference is the mechanism: stap translates the script to C and loads a kernel module, so the host needs a compiler, matching kernel headers, often debuginfo, and with Secure Boot a signed module. A bug can take the box down. BPF programs are verified bytecode and only need BTF, which RHEL 9 kernels have. The examples 01 to 06 have stap versions so you can compare side by side. On a large fleet the same properties matter even more: running a one-liner everywhere with a timeout through Ansible or pssh is easy, and for anything recurring, ship a static CO-RE binary instead of a toolchain.
