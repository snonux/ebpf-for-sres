Example 02

Who is opening which files?

$ sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat {
    printf("%-16s %s\n", comm, str(args.filename)); }'

Example output (illustrative)

Attaching 1 probe...
nginx           /var/www/html/index.html
python3         /etc/ssl/certs/ca-certificates.crt
systemd-journal /var/log/journal/.../system.journal

probe: a stable syscall tracepoint

comm: process name, built in

args.filename: the syscall argument

examples/02-opensnoop/ · opensnoop.bt · Go (ring buffer)

This is essentially opensnoop in one line. The probe fires when any process enters the openat syscall. comm is the process name, args.filename is a pointer into user memory, and str() copies the string out safely. Useful in incidents: which process keeps touching that config file, is something hammering /proc, is a service reading certificates on every request? We saw where args.filename comes from on the probes slide. Unlike the counters, this prints one line per event, so the Go version of it streams events through a ring buffer.
