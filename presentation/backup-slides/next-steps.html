Start small, this week

1  Get the examples onto a Rocky 9 staging box:

git clone https://github.com/snonux/ebpf-for-sres && cd ebpf-for-sres/examples

2  Run them all: sudo ./setup-rocky9.sh --all && sudo GO=1 ./run-all.sh

3  Rehearse the Kubernetes workflow, then let ior and an LLM look at a real service:

sudo ior -pid $(pgrep -o nginx)

Leave people with something concrete. The examples are self-testing, so running them on a staging box is the quickest way to find out what works on your fleet before you need it. For ior, see the tutorial in docs/tutorial/tutorial.md in the repository, and the blog series linked from the README. Questions.
