Example 03 · Go

Syscalls per process, counted in the kernel

Re-implements this bpftrace

tracepoint:raw_syscalls:sys_enter { @[comm] = count(); }

syscalls.bpf.c

SEC("tracepoint/raw_syscalls/sys_enter")
int count_syscalls(void *ctx) {
  char comm[16] = {};
  bpf_get_current_comm(&comm, sizeof(comm));
  u64 one = 1, *n =
      bpf_map_lookup_elem(&counts, &comm);
  if (n) __sync_fetch_and_add(n, 1);
  else bpf_map_update_elem(&counts, &comm,
                         &one, BPF_NOEXIST);
  return 0;
}

main.go

m, _ := bpfrun.Load(bpfObj, "syscalls.bpf.o", nil)
defer m.Close()
bpfrun.Wait()                      // Ctrl-C
counts, _ := m.GetMap("counts")
for it := counts.Iterator(); it.Next(); {
  k := it.Key()
  v, _ := counts.GetValue(unsafe.Pointer(&k[0]))
  rows = append(rows, row{CString(k), u64(v)})
}
sort.Slice(rows, ...)              // print like bpftrace

From here on every example is a Go program, and the strip at the top shows the bpftrace one-liner it replaces. This one counts syscalls per process name. The kernel half is the same counting pattern as example 01, on the raw_syscalls tracepoint that fires for every syscall. The user half loads the embedded object, waits for Ctrl-C, walks the map with an iterator, sorts and prints in bpftrace's format. Nothing is printed per event, so it is cheap even on a busy host.
