Where probes come from

It is all in tracefs, sysfs and ELF

Probe typeListed in

$ sudo bpftrace -l 'tracepoint:syscalls:*open*'
$ sudo bpftrace -lv kprobe:vfs_read
$ sudo bpftrace -l 'uprobe:libc:getaddr*'

examples/08-list-probes/ · list-probes.sh

bpftrace -l is not magic: it reads the same files you can read with cat. Every tracepoint has a format file describing its arguments with offsets, and that is where args.filename comes from. available_filter_functions lists the tens of thousands of kernel functions you could kprobe. The BTF file describes every kernel struct. For user space, probes come from the ELF symbol table, and USDT probes from ELF notes. On Rocky 9, tracefs is mounted at /sys/kernel/tracing. Inside a container it usually is not, which will come back in the Kubernetes part.
