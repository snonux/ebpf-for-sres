Rocky 9

dnf install bcc-tools
They land in /usr/share/bcc/tools/, not in PATH.

How they work

Python tools with C source inside, compiled when you start them. They need kernel-devel for the exact running kernel.

You do not have to write BPF to benefit from it. bcc-tools on Rocky ships dozens of ready-made tools in /usr/share/bcc/tools, which is not in PATH; Brendan Gregg's 60-second checklist with these tools is a great on-call starting point. Example 09 runs a few of them. Note how they work: each tool carries C source and compiles it on the host when it starts, against the headers of the running kernel.
