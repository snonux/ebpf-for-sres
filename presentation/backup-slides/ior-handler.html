The handler for openat, slightly trimmed

SEC("tracepoint/syscalls/sys_enter_openat")
int handle_sys_enter_openat(struct syscall_trace_enter *ctx) {
    __u32 pid, tid;
    if (filter(&pid, &tid))
        return 0;
    struct open_event *ev = bpf_ringbuf_reserve(&event_map,
                sizeof(struct open_event), 0);
    if (!ev)
        return 0;  // buffer full: event dropped
    ev->event_type = ENTER_OPEN_EVENT;
    ev->pid = pid; ev->tid = tid;
    ev->time = bpf_ktime_get_boot_ns();
    bpf_probe_read_user_str(ev->filename,
        sizeof(ev->filename), (void *)ctx->args[1]);
    bpf_get_current_comm(&ev->comm, sizeof(ev->comm));
    ev->flags = ctx->args[2];
    bpf_ringbuf_submit(ev, 0);
    return 0;
}

1  One handler per tracepoint, all generated.

2  filter() runs first, so unwanted events never reach user space.

3  Space is reserved in the ring buffer. If it is full, the event is dropped.

4  Only raw facts are recorded. Durations are computed later, in Go.

This is real code from internal/c/generated_tracepoints.c, with blank lines and a memset removed. Walk through it top to bottom. SEC names the tracepoint. filter() compares the current PID and TID with the configured filters. bpf_ringbuf_reserve gives a pointer directly into the shared ring buffer, so there is no extra copy. bpf_probe_read_user_str safely copies the filename from the process's memory; the verifier would reject a plain pointer dereference. Then submit makes the event visible to user space.
