What is running?

Inspect loaded BPF programs with bpftool

$ sudo bpftool prog show name count_writes      // without a name: every program on the box
31: tracepoint  name count_writes  tag e034ce94aa9fbb29  gpl
    loaded_at 2026-11-21T18:55:57+0000  uid 0
    xlated 200B  jited 122B  memlock 4096B  map_ids 1
    pids count_writes(1562)                       // who loaded it
$ sudo bpftool map dump name counts             // read a map from outside the tool
[{ "key": 2063, "value": 1 },{ "key": 1990, "value": 1 }, ...
$ sudo bpftool perf show                        // which PID hooked what
pid 1562  fd 6: prog_id 31  tracepoint  sys_enter_write
$ sudo bpftool prog dump xlated name count_writes  // the verified bytecode, with source lines

Real output from Rocky Linux 9.9, kernel 5.14.0-741, bpftool v7.5.0.

Find the unknown

Anything a tool, an agent or an attacker loaded shows up, with the process that loaded it. Expect systemd's own programs too.

Gone on exit

Programs unload when their loader exits, unless they are pinned under /sys/fs/bpf.

On Rocky 9

dnf install bpftool. No compiler needed: it only asks the kernel.

One more tool before the references, because sooner or later you want to know what BPF is running on a box, yours or somebody else's. bpftool asks the kernel. prog show lists every loaded program with its type, name, load time, the maps it uses and the process that loaded it. map show lists the maps, and map dump reads one from the outside while the tool is running, which is handy for debugging your own tool. perf show tells you which process attached to which tracepoint, kprobe or uprobe. prog dump xlated prints the bytecode the verifier accepted; dump jited shows the machine code. On our Rocky 9.9 test box 12 of the 14 loaded programs were systemd's own cgroup programs, so filter by name. Monitoring agents and security tools load BPF programs too. Programs disappear when the loader exits, unless they were pinned under /sys/fs/bpf. On Rocky 9 bpftool is one package, and unlike bpftrace it needs no compiler.
