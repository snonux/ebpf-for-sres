What is running?

Inspect loaded BPF programs with bpftool

$ sudo bpftool prog show                      // every BPF program loaded right now
42: tracepoint  name count_writes  tag 3f1c…  gpl
    loaded_at 2026-11-21T18:02:11  uid 0  map_ids 7
    pids count_writes(4711)                 // who loaded it
$ sudo bpftool map show                       // their maps
$ sudo bpftool map dump name counts           // read a map from outside the tool
$ sudo bpftool perf show                      // which PID hooked which tracepoint or kprobe
$ sudo bpftool prog dump xlated name count_writes  // the bytecode the verifier accepted

Find the unknown

Anything a tool, an agent or an attacker loaded shows up here, with the process that loaded it.

Gone on exit

Programs unload when their loader exits, unless they are pinned under /sys/fs/bpf.

On Rocky 9

dnf install bpftool. No compiler needed: it only asks the kernel.

One more tool before the references, because sooner or later you want to know what BPF is running on a box, yours or somebody else's. bpftool asks the kernel. prog show lists every loaded program with its type, name, load time, the maps it uses and the process that loaded it. map show lists the maps, and map dump reads one from the outside while the tool is running, which is handy for debugging your own tool. perf show tells you which process attached to which tracepoint, kprobe or uprobe. prog dump xlated prints the bytecode the verifier accepted; dump jited shows the machine code. Monitoring agents, security tools and systemd load BPF programs too, so expect to see more than your own. Programs disappear when the loader exits, unless they were pinned under /sys/fs/bpf. On Rocky 9 bpftool is one package, and unlike bpftrace it needs no compiler.
