Kubernetes: debug a pod's /store IOPS

Ephemeral debug container + static BPF binary

$ kubectl debug -it pod/app-7d9f --target=app --profile=sysadmin \
    --image=busybox --container=ebpf-debug -- sh   // 1. root, app's PID ns
$ kubectl cp storeiops app-7d9f:/tmp/storeiops -c ebpf-debug           // 2. upload (2nd terminal)
/ # ps                                                                  // 3. app's processes
    1 root  java -jar app.jar
/ # ls /proc/1/root/store                                               //    app's /store (EFS)
/ # /tmp/storeiops -pid 1 -path /store -bycomm                        // 4. trace

Output (illustrative)

16:02:11     PID COMM     OP      IOPS   MiB/s   AVG_us   MAX_us  ERR
               - java     write   1840    7.19     21.4   2210.9    0
               - java     fsync     92    0.00   8410.2  41022.7    0
               - java     close     88    0.00   5120.6  30219.0    0

--target: share the app's PID namespace

--profile=sysadmin: privileged, root

/proc/1/root: the app's file system

exit: programs unload

The whole workflow on one slide. One: kubectl debug adds an ephemeral container to the running pod. target puts it into the app container's PID namespace so we can see its processes; the sysadmin profile makes it privileged, which loading BPF needs. The image is plain busybox: it runs as root and has a shell and tar, the app image has neither. Careful with images that default to a non-root user, like Chainguard's busybox: even privileged, a non-root user cannot load BPF. Two: copy in the static binary. Three: ps shows the app as PID 1, and /proc/1/root/store is the app's view of its EFS volume. Four: run storeiops with that PID and path. Here we would see that fsync and close are the slow operations, which is typical for NFS because that is when dirty data goes to the server. When you exit, the programs are unloaded. The ephemeral container stays in the pod spec as terminated until the pod is replaced. The namespace's Pod Security level must allow privileged containers.
