Every example: mage · sudo -E mage test · mage static. All passed in the sandbox except 06 (no kprobes there).

A quick flyover, not a walkthrough: the point is that once you have seen one, you have seen them all. Each one is a BPF C file and a Go file of about fifty lines. They differ only in which hook they use and in how the data comes back: a map read at the end, a map read per slot, or a ring buffer drained continuously. Pick any one to read after the talk. The last line is the one we look at in detail now.
