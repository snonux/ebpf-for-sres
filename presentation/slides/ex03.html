Example 03

Syscalls per process, counted in the kernel

$ sudo bpftrace -e 'tracepoint:raw_syscalls:sys_enter { @[comm] = count(); }'

Output from the sandbox run

^C
@[sleep]: 1537
@[ls]: 5544
@[cat]: 19360
@[bash]: 43151

Same program as 01

Only the probe changed: raw_syscalls:sys_enter fires for every syscall.

Nothing per event

The map is printed once, on Ctrl-C. Cheap even on a busy host.

examples/03-syscalls-per-process/ · syscalls.bt · syscalls.stp · Go

Swap one probe and the same three lines answer a different question: which process is making the most syscalls. Note that nothing is printed per event: the counting happens in a kernel map and only the summary crosses into user space when you press Ctrl-C. That is why this is safe to run on a busy host. The output is from the sandbox test run with the workload script.
