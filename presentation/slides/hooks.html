Hooks

Where you can attach a program

Tracepoints

Stable, documented kernel events: syscalls, scheduler, block I/O. ior uses these.

kprobes, fentry

Almost any kernel function. Powerful, but tied to kernel internals.

uprobes, USDT

Functions in user binaries: libc, the JVM, databases, your own services.

perf events

Timed sampling for CPU profiles and flame graphs.

XDP, tc

Packets at the network driver or traffic-control layer: load balancers, DDoS filters.

LSM, cgroups

Security policy and per-container controls.

For observability the top row matters most. Tracepoints are a stable interface the kernel promises to keep; kprobes can hook nearly any kernel function but may break across kernel versions. uprobes do the same for user-space code. The bottom row shows eBPF is not only for tracing: Cilium, Katran and others run networking and security in eBPF too.
