On call

Before you run it on a production box

Mind the event rate

Tracing every read on a busy database adds up. Filter by PID and aggregate in the kernel.

Buffers can fill up

When the ring buffer is full, events are dropped. In ior, raise -mapSize.

Check the kernel

You need BTF (/sys/kernel/btf/vmlinux). Ring buffers need kernel 5.8 or newer.

It needs privileges

Root, or CAP_BPF plus CAP_PERFMON. Treat it like any other root tool.

Practical checklist. Start with a short -duration and a PID filter, watch the host's CPU while tracing, and prefer aggregation over per-event output on hot paths. Most modern distributions ship BTF-enabled kernels (RHEL 8.2+, Ubuntu 20.10+, recent Debian and Fedora), but check before an incident, not during one.
