On call

Before you run it on a production box

Mind the event rate

Tracing every read on a busy database adds up. Filter by PID and aggregate in the kernel.

Buffers can fill up

When the ring buffer is full, events are dropped. Count drops, as example 10 does.

Check the kernel

BTF must exist (/sys/kernel/btf/vmlinux). On Rocky 9 it does; bcc also needs kernel-devel for the running kernel.

It needs privileges

Root, or CAP_BPF plus CAP_PERFMON. Treat it like any other root tool.

Practical checklist. Start with a short -duration and a PID filter, watch the host's CPU while tracing, and prefer aggregation over per-event output on hot paths. Most modern distributions ship BTF-enabled kernels (RHEL 8.2+, Ubuntu 20.10+, recent Debian and Fedora), but check before an incident, not during one: run examples/run-all.sh on a representative box now. In Kubernetes, the namespace must allow a privileged debug container, which is worth arranging with the platform team before you need it.
