Try it: bpftrace one-liners

bpftrace is awk for kernel events. Every program has the same shape:

probe /filter/ { action }

Rocky 9.9: sudo dnf install bpftrace, or examples/setup-rocky9.sh for everything. Each example also comes as SystemTap and as Go.

Switch to a terminal if you can and run these live. bpftrace compiles the script to BPF, loads it, and prints map contents when you press Ctrl-C. The filter is optional. Syntax note: recent bpftrace versions, including the one in Rocky 9.9, write tracepoint arguments as args.name; versions before 0.20 use args->name. Every example directory has the bpftrace script, a SystemTap script where it makes sense, and a Go program with libbpfgo; run-all.sh tests them all.
