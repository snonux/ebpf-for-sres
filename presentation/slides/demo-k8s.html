Second demo, about five minutes. Build the static binary before the talk. podman-demo.sh reproduces the Kubernetes setup on one Rocky box: an app container writing to a /store volume, a privileged debug container in the app's PID namespace, a podman cp of the binary, and then storeiops tracing PID 1. Point out that the reads of /etc/os-release by the same app never show up, because they are not on /store, and that nothing from the host appears either. If you have a cluster, do the real kubectl version instead.
