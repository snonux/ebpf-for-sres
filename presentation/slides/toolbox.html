On the fleet

Ad hoc: the same one-liner on every host, with a timeout:

ansible all -m shell -a "timeout 10 bpftrace -e '…'"

Recurring: ship a static CO-RE binary with config management.

You do not have to write BPF to benefit from it. bcc-tools on Rocky ships dozens of ready-made tools in /usr/share/bcc/tools, which is not in PATH; Brendan Gregg's 60-second checklist with these tools is a great on-call starting point. Note they compile on the host, so they need kernel-devel for the running kernel. On a fleet, running a one-liner everywhere with a timeout through Ansible or pssh is easy; for anything recurring, ship a static CO-RE binary instead of a toolchain.
