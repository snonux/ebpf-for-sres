Example 09: ready-made

Tools worth knowing before your next page

ToolAnswers
execsnoopWhich short-lived processes keep spawning?
opensnoopWhich files are being opened, and are the opens failing?
biolatencyHow slow is the disk, as a latency histogram?
runqlatAre threads waiting for a CPU?
tcplife, tcpretransWhich TCP sessions, how long, any retransmits?
profileWhere is CPU time spent? Feeds flame graphs.

Rocky 9: dnf install bcc-tools → /usr/share/bcc/tools/ (needs kernel-devel for the running kernel). examples/09-bcc-tools/

You do not have to write BPF to benefit from it. These tools ship with bcc-tools on Rocky and live in /usr/share/bcc/tools, which is not in PATH. Brendan Gregg's 60-second checklist with these tools is a great on-call starting point. Many of our examples are small versions of these tools, which is a good way to understand what they measure.
