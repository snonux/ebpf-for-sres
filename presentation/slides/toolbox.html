On the grid: ad hoc, the same one-liner everywhere with a timeout:

ansible all -m shell -a "timeout 10 bpftrace -e '…'"

Recurring: ship a static CO-RE binary with config management.

You do not have to write BPF to benefit from it. bcc-tools on Rocky ships dozens of ready-made tools in /usr/share/bcc/tools, which is not in PATH; Brendan Gregg's 60-second checklist with these tools is a great on-call starting point. Note they compile on the host, so they need kernel-devel for the running kernel. Many of you know SystemTap, which did all of this years before BPF. The difference is the mechanism: stap translates the script to C and loads a kernel module, so the host needs a compiler, matching headers and often debuginfo, Secure Boot needs a signed module, and a bug can take the box down. BPF programs are verified bytecode and only need BTF. Examples 01 to 06 have stap versions to compare. On a fleet, running a one-liner everywhere with a timeout through Ansible or pssh is easy; for anything recurring, ship a static CO-RE binary instead of a toolchain.
