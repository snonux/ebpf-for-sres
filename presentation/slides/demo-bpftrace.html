bpftrace live on Rocky 9.9

$ cd examples && sudo ./setup-rocky9.sh --all     // beforehand
$ sudo ./01-opens-per-process/opens.bt           // Ctrl-C: counts
$ sudo ./02-opensnoop/opensnoop.bt               // who opens what, live
$ sudo bpftrace -d all ./01-opens-per-process/opens.bt | less
                                                 // the compiler at work

Fallback if the network or the box misbehaves: examples/results/ has the output of every example.

Live demo, about two minutes, and the only bpftrace we run live. Do the setup beforehand, not on stage. Run opens.bt for a few seconds and press Ctrl-C to show the counts, then opensnoop for live events, and finally bpftrace -d all on the same script to show the parser, semantic analysis and LLVM IR scrolling by: that is the compiler from the previous slide doing its work on the host. If anything goes wrong, the results directory has recorded output to show instead.
