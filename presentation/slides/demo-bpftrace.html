Demo 1 · 2 min

bpftrace live on Rocky 9.9

$ sudo dnf install bpftrace              // all it needs
$ sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat { @[comm] = count(); }'
$ sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat {
      printf("%-16s %s\n", comm, str(args.filename)); }'
$ sudo bpftrace -d all -e 'tracepoint:syscalls:sys_enter_openat { @[comm] = count(); }' | less
      // -d all: watch bpftrace compile the script

Fallback if the network or the box misbehaves: examples/results/ has the output of every example.

Live demo, about two minutes, and the only bpftrace we run live. No wrapper scripts: type the two one-liners from the previous slide. Run the count for a few seconds and press Ctrl-C to show the map, then the stream for live events. Finally run the first one again with -d all and page through the output: the syntax tree, the resolved types and the LLVM IR scroll by. Leave that on screen for a moment, because it is the point of the next two slides: bpftrace just ran a compiler on this host. If anything goes wrong, examples/results has recorded output.
