An introduction for SREs and developers

eBPF: safe little programs
inside the Linux kernel

What it is, why it is safe on production boxes, how to write tools: bpftrace one-liners, and BPF programs in C (or Rust) loaded from a Go program, how to use it inside a Kubernetes pod, and where LLMs fit in. Every example runs on Rocky Linux 9.9.

Paul Buetow

$ sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat { @[comm] = count(); }'

Goal of this talk, about 45 minutes including three demos, questions at the end, 50 in total: you know what BPF is and why it is safe on production boxes, can run the one-liners yourself, understand CO-RE and how a small tool is put together: the BPF program itself in restricted C, loaded and read by Go with libbpfgo (the program could also be written in Rust with Aya, and the loader in C, Rust or Python), can trace a Kubernetes pod from a debug container, and see how an LLM turns a syscall trace plus source code into a diagnosis. All examples are in the examples/ directory of this repository and run on Rocky Linux 9.9. The command at the bottom counts file opens per process name; we will come back to it.
